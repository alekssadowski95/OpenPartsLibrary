they support the project's goal: making reusable CAD parts, BOM data, and
machine-building workflows easier to share and maintain.

## How to Contribute

- Open an issue before starting large changes.
- Keep pull requests focused on one topic.
- Include a clear description of the problem and the proposed solution.
- Update documentation when behavior, setup, or user workflows change.
- Prefer practical improvements for CAD reuse, BOM handling, search quality,
  FreeCAD workflows, translations, and data quality.

## Code and Data Quality

- Follow the style already used in the surrounding files.
- Keep changes small and easy to review.
- Do not include generated files unless they are required by the project.
- Check that new CAD, image, translation, and data files can be redistributed.
- Avoid adding supplier data, product images, CAD files, or text from third
  parties unless the license clearly permits redistribution in this repository.
